# 시연 時緣

한국사 기반 역사 체험 UI. **Next.js App Router · TypeScript · Tailwind CSS 4**를 사용합니다.

## 실행

Node.js 20.9 이상에서:

```sh
npm ci
npm run dev
```

http://127.0.0.1:3000 에서 확인합니다.

```sh
npm run test
npm run typecheck
npm run build
```

정적 내보내기 결과는 `out/`에 생성됩니다. `npm start`는 포함된 Node 정적 서버로 빌드 결과를 http://127.0.0.1:3000 에서 보여줍니다. 배포 시에는 정적 호스팅으로 `out/`을 서비스하세요. 모든 경로를 디렉터리의 `index.html`에 매핑하는 서버를 사용합니다.

Windows 제한 환경의 SWC 경로 접근 오류를 피하기 위해 `.babelrc`의 `next/babel`과 Webpack을 사용합니다. Next.js App Router 구조는 동일합니다.

## 페이지

- `/`: 소개, 체험 안내, 시대 예시, 콘텐츠 구분
- `/analyze/`: 생년월일, 양력·음력, 윤달, 시간·모름, 출생 지역 입력
- `/result/`: 성향·오행 예시, 시대 TOP3, 인물 TOP3, 직업 TOP3, 가상 일생 탭
- `/my-history/`: 브라우저 로컬 기록 목록, 다시 열기, 개별·전체 삭제

## 데이터의 경계

실제 AI 호출, 만세력, 사주 계산, 음양력 변환은 없습니다. 모든 입력에 같은 mock 결과를 제공하며, 순위와 오행 비율도 고정 예시입니다. 입력 화면·결과 화면·푸터에 명시합니다.

- **역사적 사실**: 녹색 배지, 국사편찬위원회 우리역사넷 출처 링크
- **명리학 해석 · 예시**: 보라색 배지, 전통 개념에서 착안한 가상 성향
- **창작**: 금색 배지, 추천과 직업 역할명·가상 일생

양력은 실제 달력의 일수·윤년·미래 날짜를 검증합니다. 음력은 1~12월, 1~30일의 형식과 입력 범위만 검사하며 실제 음력 유효성·윤달 여부·양력 변환은 검증하지 않습니다. 제한은 폼에 표시합니다. 지역은 미리 정의된 선택지입니다. 서버로 출생 데이터를 보내지 않습니다.

## 저장과 오류

임시 입력은 `sessionStorage`, 사용자가 저장한 기록은 `localStorage`에 최대 20개 보관합니다. 버전과 형식을 검증하고 손상된 기록 또는 저장소 차단은 오류로 안내합니다. 기록이 없으면 빈 화면 안내를 표시합니다. 다른 브라우저·기기와 동기화되지 않습니다.

재사용 구성은 `src/components/`, 데이터·검증·저장 로직은 `src/lib/`에 있습니다. App Router의 `loading.tsx`, `error.tsx`, `not-found.tsx`와 제출 중 로딩 상태를 제공합니다. 키보드 결과 탭, 삭제 모달 포커스 순환, 본문 건너뛰기, reduced-motion 및 모바일 메뉴를 지원합니다.

풍경은 외부 이미지 없이 자체 SVG로 제작한 창작 일러스트입니다. 한국어 서체는 시스템 폰트 대체 목록을 사용해 빌드 시 외부 폰트 다운로드가 필요하지 않습니다.

## 테스트

기본 테스트는 입력 검증(양력 윤년, 날짜 범위, 시간 모름, 윤달), 한국 시간 날짜 경계, 저장 형식·손상 데이터 처리, 기록 중복 제거·최대 개수, TOP3 데이터 구성을 확인합니다.

이번 실행에서 11개 기본 테스트, TypeScript 검사, 프로덕션 정적 빌드가 통과했습니다. 브라우저 미리보기는 이 환경의 localhost 연결 시간 초과로 확인하지 못했으므로 실제 화면·클릭·모바일 브라우저 검증은 미완료입니다. 사이트 소스 업로드는 세션의 자동 승인 정책이 거부하여 호스팅 배포는 완료하지 않았습니다.
